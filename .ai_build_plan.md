# Choose-Your-Monster - AI Build Blueprint

This hidden file contains instructions for AI agents modifying this repository.

## Architecture
- This is a frontend-heavy React application built with Vite and styled using Tailwind CSS v4.
- Animations are handled via \ramer-motion\.
- All data is statically stored in JSON files under \src/data/\ (e.g., \members.json\, \memes.json\).

## Rules for AI Agents
1. When adding new "monsters" or content, do NOT edit components directly; update the corresponding JSON files in \src/data/\.
2. Ensure any new Framer Motion animations strictly adhere to the existing easing curves (\easeInOut\) to maintain the application's unique feel.
3. The UI MUST remain responsive on mobile devices; use Tailwind's \md:\ and \lg:\ prefixes.
4. Do NOT introduce a backend or database. This application is designed to be fully static and hostable on Vercel/GitHub Pages.
