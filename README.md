## 🌟 Overview
**Choose-Your-Monster** is a beautifully crafted frontend web application that acts as an interactive directory and roster for various "monsters", memes, and TikTok videos. It is designed to be highly engaging with smooth animations powered by Framer Motion, and a modern aesthetic styled with Tailwind CSS v4.

## 🚀 Key Features
| Feature | Description |
| :--- | :--- |
| 🎬 **Framer Motion Animations** | Smooth, physics-based page transitions and component reveals. |
| 🎨 **Tailwind CSS v4** | Highly responsive, utility-first styling tailored for an engaging UI. |
| ⚡ **Vite Powered** | Blazing fast Hot Module Replacement (HMR) for local development. |
| 📂 **Static JSON Data** | Fully independent frontend, populated dynamically via \src/data\ JSON files. |

## 🛠️ Built With
- **Framework:** React 19 + Vite
- **Styling:** Tailwind CSS v4
- **Animations:** Framer Motion
- **Icons:** Lucide React

## 🚀 Getting Started
This is a standard Vite React project.
1. Navigate into the subfolder: \cd choose-your-monster\
2. Install dependencies: \
pm install\
3. Start the dev server: \
pm run dev\
